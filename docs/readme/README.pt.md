## Recursos

- **435 aplicativos** instalados com **winget** ou **Chocolatey**, com ícones e tamanho de download.
- **Tweaks, Debloat e Config** com desfazer e **ponto de restauração automático** antes de ações arriscadas.
- **Drivers**: verifica o hardware, compara com o Microsoft Update Catalog e mostra «de X para Y».
- **Limpeza** que informa o espaço realmente liberado.
- **12 idiomas**, visual Classic ou Modern, claro ou escuro; as mudanças são aplicadas **na hora**.
- Fica na bandeja do sistema; gerenciador de downloads opcional **R-Downloader** (multiconexão, torrents, extensão para navegador).

## Instalação

1. Baixe `RockToolbox-Setup-4.1.0.exe` em [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest).
2. Execute-o e escolha o idioma e as opções (R-Downloader, ícone, iniciar com o Windows).
3. Abra o Rock Toolbox; o aplicativo pedirá permissão de administrador.

## Requisitos

Windows 10 ou 11 (64 bits), .NET Framework 4.x (incluído no Windows), permissão de administrador, acesso à Internet.
