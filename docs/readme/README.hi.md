## विशेषताएँ

- **winget** या **Chocolatey** से **435 ऐप** इंस्टॉल करें, आइकन और डाउनलोड साइज़ के साथ।
- **Tweaks, Debloat और Config** में Undo की सुविधा, और जोखिम भरे काम से पहले **अपने-आप रिस्टोर पॉइंट**।
- **ड्राइवर**: हार्डवेयर स्कैन, Microsoft Update Catalog से तुलना, और «X से Y» के रूप में नतीजा।
- **क्लीनअप** जो असल में खाली हुई जगह बताता है।
- **12 भाषाएँ**, Classic या Modern लुक, लाइट या डार्क; बदलाव **तुरंत** लागू होते हैं।
- ट्रे में चलता रहता है; वैकल्पिक डाउनलोड मैनेजर **R-Downloader** (मल्टी-कनेक्शन, टोरेंट, ब्राउज़र एक्सटेंशन)।

## इंस्टॉलेशन

1. [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest) पेज से `RockToolbox-Setup-4.1.0.exe` डाउनलोड करें।
2. इसे चलाएँ, भाषा और विकल्प चुनें (R-Downloader, आइकन, Windows के साथ शुरू)।
3. Rock Toolbox खोलें; ऐप एडमिनिस्ट्रेटर अनुमति माँगेगा।

## ज़रूरतें

Windows 10 या 11 (64-बिट), .NET Framework 4.x (Windows में शामिल), एडमिनिस्ट्रेटर अधिकार, इंटरनेट कनेक्शन।
