## Funzionalità

- **435 app** installate con **winget** o **Chocolatey**, con icone e dimensione del download.
- **Tweaks, Debloat e Config** con annullamento e **punto di ripristino automatico** prima delle azioni rischiose.
- **Driver**: analizza l'hardware, confronta con il Microsoft Update Catalog e mostra «da X a Y».
- **Pulizia** che indica lo spazio realmente liberato.
- **12 lingue**, aspetto Classic o Modern, chiaro o scuro; le modifiche si applicano **subito**.
- Resta nell'area di notifica; gestore di download opzionale **R-Downloader** (multi-connessione, torrent, estensione per il browser).

## Installazione

1. Scarica `RockToolbox-Setup-4.1.0.exe` da [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest).
2. Eseguilo e scegli lingua e opzioni (R-Downloader, icona, avvio con Windows).
3. Apri Rock Toolbox; l'app richiede i permessi di amministratore.

## Requisiti

Windows 10 o 11 (64 bit), .NET Framework 4.x (incluso in Windows), permessi di amministratore, connessione a Internet.
