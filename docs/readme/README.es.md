## Características

- **435 aplicaciones** instaladas con **winget** o **Chocolatey**, con iconos y tamaño de descarga.
- **Tweaks, Debloat y Config** con opción de deshacer y **punto de restauración automático** antes de acciones arriesgadas.
- **Controladores**: analiza el hardware, compara con el Microsoft Update Catalog y muestra «de X a Y».
- **Limpieza** que informa del espacio realmente liberado.
- **12 idiomas**, aspecto Classic o Modern, claro u oscuro; los cambios se aplican **al instante**.
- Se queda en la bandeja del sistema; gestor de descargas opcional **R-Downloader** (multiconexión, torrents, extensión para el navegador).

## Instalación

1. Descarga `RockToolbox-Setup-4.1.0.exe` desde [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest).
2. Ejecútalo y elige el idioma y las opciones (R-Downloader, icono, inicio con Windows).
3. Abre Rock Toolbox; la aplicación pedirá permisos de administrador.

## Requisitos

Windows 10 u 11 (64 bits), .NET Framework 4.x (incluido en Windows), permisos de administrador, conexión a Internet.
