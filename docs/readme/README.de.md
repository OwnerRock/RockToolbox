## Funktionen

- **435 Apps** über **winget** oder **Chocolatey** installieren, mit Symbolen und Downloadgröße.
- **Tweaks, Debloat und Config** mit Rückgängig-Funktion und **automatischem Wiederherstellungspunkt** vor riskanten Aktionen.
- **Treiber**: Hardware-Scan, Vergleich mit dem Microsoft Update Catalog, Anzeige „von X auf Y“.
- **Bereinigung**, die den tatsächlich freigegebenen Speicher meldet.
- **12 Sprachen**, Look Classic oder Modern, hell oder dunkel; Änderungen gelten **sofort**.
- Läuft im Infobereich weiter; optionaler Download-Manager **R-Downloader** (Mehrfachverbindungen, Torrents, Browser-Erweiterung).

## Installation

1. Laden Sie `RockToolbox-Setup-4.1.0.exe` von [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest) herunter.
2. Starten Sie die Datei und wählen Sie Sprache und Optionen (R-Downloader, Symbol, Autostart).
3. Öffnen Sie Rock Toolbox; die App fordert Administratorrechte an.

## Voraussetzungen

Windows 10 oder 11 (64 Bit), .NET Framework 4.x (in Windows enthalten), Administratorrechte, Internetzugang.
