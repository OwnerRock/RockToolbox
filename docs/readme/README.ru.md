## Возможности

- **435 приложений** устанавливаются через **winget** или **Chocolatey**, с иконками и размерами загрузки.
- **Tweaks, Debloat и Config** с отменой изменений и **автоматической точкой восстановления** перед рискованными действиями.
- **Драйверы**: сканирование оборудования, сравнение с Microsoft Update Catalog, показ «с X на Y».
- **Очистка** показывает, сколько места освобождено на самом деле.
- **12 языков**, вид Classic или Modern, светлая или тёмная тема; изменения применяются **мгновенно**.
- Работает в трее; дополнительный менеджер загрузок **R-Downloader** (многопоточность, торренты, расширение для браузера).

## Установка

1. Скачайте `RockToolbox-Setup-4.1.0.exe` на странице [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest).
2. Запустите файл, выберите язык и параметры (R-Downloader, значок, автозапуск).
3. Откройте Rock Toolbox; приложение запросит права администратора.

## Требования

Windows 10 или 11 (64 бит), .NET Framework 4.x (входит в Windows), права администратора, доступ в интернет.
