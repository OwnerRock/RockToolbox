## Özellikler

- **winget** veya **Chocolatey** ile kurulan **435 uygulama**; simgeler ve indirme boyutlarıyla.
- Geri alma destekli **Tweaks, Debloat ve Config**; riskli işlemlerden önce **otomatik geri yükleme noktası**.
- **Sürücüler**: donanımı tarar, Microsoft Update Catalog ile karşılaştırır, «X sürümünden Y sürümüne» gösterir.
- Gerçekte açılan alanı bildiren **Temizlik**.
- **12 dil**, Classic veya Modern görünüm, açık veya koyu tema; değişiklikler **anında** uygulanır.
- Sistem tepsisinde çalışmaya devam eder; isteğe bağlı indirme yöneticisi **R-Downloader** (çoklu bağlantı, torrent, tarayıcı eklentisi).

## Kurulum

1. [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest) sayfasından `RockToolbox-Setup-4.1.0.exe` dosyasını indirin.
2. Çalıştırın; dili ve seçenekleri (R-Downloader, simge, Windows ile başlat) seçin.
3. Rock Toolbox'ı açın; uygulama yönetici izni ister.

## Gereksinimler

Windows 10 veya 11 (64 bit), .NET Framework 4.x (Windows ile gelir), yönetici hakları, internet bağlantısı.
