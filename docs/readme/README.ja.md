## 機能

- **winget** または **Chocolatey** で **435 個のアプリ**をインストール。アイコンとダウンロードサイズ付き。
- 元に戻せる **Tweaks、Debloat、Config**。危険な操作の前に**復元ポイントを自動作成**。
- **ドライバー**：ハードウェアをスキャンし、Microsoft Update Catalog と比較して「X から Y へ」と表示。
- 実際に空いた容量を報告する**クリーンアップ**。
- **12 言語**、Classic / Modern の外観、ライト / ダーク。変更は**即時反映**。
- タスクトレイに常駐。オプションのダウンロードマネージャー **R-Downloader**（マルチ接続、トレント、ブラウザー拡張）。

## インストール

1. [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest) から `RockToolbox-Setup-4.1.0.exe` をダウンロードします。
2. 実行して、言語とオプション（R-Downloader、アイコン、Windows 起動時に開始）を選びます。
3. Rock Toolbox を開きます。管理者権限を求められます。

## 動作環境

Windows 10 または 11（64 ビット）、.NET Framework 4.x（Windows に含まれます）、管理者権限、インターネット接続。
