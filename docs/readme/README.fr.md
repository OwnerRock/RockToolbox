## Fonctionnalités

- **435 applications** installées via **winget** ou **Chocolatey**, avec icônes et tailles de téléchargement.
- **Tweaks, Debloat et Config** avec annulation et **point de restauration automatique** avant les actions risquées.
- **Pilotes** : analyse du matériel, comparaison avec le Microsoft Update Catalog, affichage « de X vers Y ».
- **Nettoyage** qui indique l'espace réellement libéré.
- **12 langues**, look Classic ou Modern, clair ou sombre ; les changements s'appliquent **instantanément**.
- Reste dans la zone de notification ; gestionnaire de téléchargement optionnel **R-Downloader** (multi-connexions, torrents, extension navigateur).

## Installation

1. Téléchargez `RockToolbox-Setup-4.1.0.exe` depuis la page [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest).
2. Lancez-le, choisissez la langue et les options (R-Downloader, icône, démarrage avec Windows).
3. Ouvrez Rock Toolbox ; l'application demande les droits administrateur.

## Configuration requise

Windows 10 ou 11 (64 bits), .NET Framework 4.x (inclus dans Windows), droits administrateur, accès Internet.
