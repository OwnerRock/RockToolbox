## 功能

- 通过 **winget** 或 **Chocolatey** 安装 **435 款应用**，带图标和下载大小。
- **Tweaks、Debloat 和 Config** 支持撤销，并在高风险操作前**自动创建还原点**。
- **驱动程序**：扫描硬件，与 Microsoft Update Catalog 比较，显示“从 X 到 Y”。
- **清理**会报告真正释放的空间。
- **12 种语言**，Classic 或 Modern 外观，浅色或深色；更改**立即生效**。
- 常驻系统托盘；可选的下载管理器 **R-Downloader**（多连接、种子、浏览器扩展）。

## 安装

1. 在 [Releases](https://github.com/OwnerRock/RockToolbox/releases/latest) 页面下载 `RockToolbox-Setup-4.1.0.exe`。
2. 运行安装程序，选择语言和选项（R-Downloader、图标、开机启动）。
3. 打开 Rock Toolbox；程序会请求管理员权限。

## 系统要求

Windows 10 或 11（64 位）、.NET Framework 4.x（Windows 自带）、管理员权限、网络连接。
